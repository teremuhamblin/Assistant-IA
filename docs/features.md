# ✨ Features — The MadDoG.tmdg

Ce document liste les fonctionnalités actuelles et les évolutions prévues du projet.

## Fonctionnalités actuelles (v1.0)
- Assistant IA minimal (JS + Lisp)
- Réponses statiques basées sur mots-clés
- Structure modulaire du projet
- Documentation progressive

## Fonctionnalités prévues (v1.1 → v1.2)
- Logique IA conditionnelle améliorée
- Interface utilisateur interactive
- Intégration du moteur Lisp dans la démo
- Personnalisation du ton de l’assistant

## Objectifs
- Garder le projet simple, pédagogique et évolutif
- Préparer une base solide pour une version avancée
