# 🦊 Overview

**Asistant-IA** est un mini projet de présentation intégrant un assistant IA simple,
conçu pour démontrer une structure claire, modulaire et progressive.

## Vision
Créer un assistant IA minimaliste, compréhensible, extensible et utilisable comme base
pour des versions plus avancées.

## Structure du projet
- `.github/` — Parametrage du projet
- `design/`  — Graphisme 
- `docs/` — Documentation officielle
- `script/` — Logique IA (JS + Lisp)
- `assets/` — Identité visuelle
- `README.md` — Présentation générale

## Public visé
- Développeurs souhaitant comprendre une architecture simple
- Utilisateurs curieux d’un assistant IA minimal
- Base pour expérimentations futures
