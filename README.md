### 📖 À propos du projet
>Base V1.0.0
- Projet personnel de présentation avec assistant IA
- Ce document décrit le fonctionnement conceptuel de l’assistant IA intégré au projet.

### 🎯 Objectif
Fournir un assistant IA minimaliste, simple à comprendre, facile à étendre, et utilisable
comme base pour des versions plus avancées.

## 🧠 Architecture
- **Niveau 1 (v1.0)** : réponses statiques, sans contexte.
- **Niveau 2 (v1.1)** : logique conditionnelle simple.
- **Niveau 3 (v1.2)** : mini‑moteur IA en Lisp (expérimental).
- **Niveau 4 (v1.3)** : test et exploitation (expérimental).


### 🔧 Technologies
- JavaScript pour l’interface utilisateur.
- Lisp pour la logique IA expérimentale.
- Structure modulaire pour évoluer vers une version API.

### 📌 Notes
Ce module est volontairement minimal afin de rester pédagogique et extensible.
