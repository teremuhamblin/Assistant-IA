# 🎨 Dossier `assets/`

Ce dossier regroupe les ressources visuelles du projet.

## Contenu
- `logo.png` — Logo du projet  
- `avatar.png` — Avatar de l’assistant IA  
- `banner.png` — Visuel principal  
- `preview.png` — Aperçu pour README ou réseaux  

## Objectif
Centraliser l’identité visuelle du projet pour une utilisation cohérente dans l’interface et la documentation.

## Bonnes pratiques
- Utiliser des noms de fichiers explicites  
- Optimiser les images avant intégration  
- Organiser par sous‑dossiers si le volume augmente
