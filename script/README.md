# ⚙️ Dossier `script/`

Ce dossier contient la logique fonctionnelle du projet, incluant l’assistant IA et les scripts de démonstration.

## Contenu
```text
- `ai-core.js` — Réponses IA simples en JavaScript  
- `assistant-ia.lisp` — Mini moteur IA expérimental en Lisp  
- `config.js` — Configuration globale du projet  
- `demo.js` — Script de démonstration pour l’interface  
```

## Objectif
Fournir une base modulaire pour l’évolution de l’assistant IA et des interactions utilisateur.

## Bonnes pratiques
- Garder les modules courts et spécialisés  
- Éviter la duplication de logique  
- Préparer les fichiers pour une future API
